Clang/LLD compiled to WebAssembly, from the npm package microbit-clang-wasm 21.11.0-alpha.1
(https://github.com/carlosperate/microbit-clang-wasm, derived from YoWASP/clang). Unmodified, except that
llvm.core.wasm and llvm-resources.tar are stored gzipped; compiler/worker.js decompresses them.
