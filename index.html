Compiling on GitHub for
Connect GitHub to compile

Sketches are saved to your repo and compiled there by GitHub Actions, then uploaded to the board from this page. That needs a GitHub token.

  1. Create a fine-grained token.
  2. Under Repository access pick Only select repositories and choose this repo.
  3. Under Permissions set Contents and Actions to Read and write.
  4. Generate it, copy it, and paste it here.

The token stays in this browser on this phone and is only sent to api.github.com.
